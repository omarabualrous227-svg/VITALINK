CONCURRENCY SAFETY
- Each accepted server write increments serverRevision.
- Clients must send expectedRevision.
- A stale write receives HTTP 409 and does not overwrite the newer server state.

FALLBACK
- Same-browser BroadcastChannel/localStorage synchronization remains available if the backend is temporarily unavailable.
- START_VITALINK_WINDOWS.bat attempts the Express + ws server first.
- If npm dependency installation fails, the launcher starts server-lite.js automatically.

ENVIRONMENT LIMITATION
- This environment blocked Chromium navigation to localhost with ERR_BLOCKED_BY_ADMINISTRATOR.
- Therefore a real browser multi-page localhost session could not be executed here.
- The REST/SQLite/WebSocket backend itself was executed and tested, including four simultaneous WebSocket clients.
- The Express server was syntax-checked. Its runtime dependency installation could not be completed in this environment because npm network installation timed out.
- The zero-dependency backend uses the same frontend API/WebSocket contract and was runtime-tested successfully.

SECURITY / MVP BOUNDARY
