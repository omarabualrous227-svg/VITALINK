# VITALINK 2076 Complete Project Bundle

This bundle combines the existing v30 multi-device backend package with the unchanged v30 backend-aware frontend and a separately documented synthetic dataset.

The original backend archive files were copied without editing their contents. The original frontend is byte-identical in both `public/index.html` and `frontend/VITALINK_Irbid_MVP_v30_BackendAware.html`.

See `README_AR.md` for the primary run guide in Arabic and `dataset/README_DATASET.md` for dataset scope and limitations.
